EL PROYECTO

Acerca de la plataforma

El objetivo de este sitio es ser una base de datos e informacion acerca de cada tarea dentro de una obra, tanto de materiales como de mano de obra o equipos, asi como tambien cantidad de los mismos, consumos, rendimientos, etc. Por el momento no tiene como objeto el calculo de computo y presupuesto dentro de un proyecto, sino mas bien un lugar donde se pueda sacar informacion de manera precisa y ordenada, y luego volcarla a un programa de calculo.
